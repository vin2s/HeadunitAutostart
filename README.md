# Автозапуск магнитолы

Android-приложение для автомагнитол: после включения или пробуждения ГУ запускает выбранную программу и сворачивает её на рабочий стол. После настройки работает в фоне.

## Зачем это нужно

Многие магнитолы после сна или ACC ON не поднимают нужное приложение сами. Это приложение:

1. Стартует по `BOOT_COMPLETED`, QuickBoot, подключению питания и `SCREEN_ON`.
2. Ждёт заданную паузу (пока система магнитолы догрузится).
3. Запускает выбранное приложение.
4. Через вторую паузу отправляет Home и сворачивает его.
5. Держит foreground-службу, чтобы не быть убитым во сне.

## Настройка на магнитоле

1. Скачайте APK и установите его.
2. Откройте **Автозапуск магнитолы**.
3. Выберите приложение (Яндекс.Музыка, карты, плеер и т.п.).
4. При необходимости измените паузы.
5. Разрешите показ поверх других окон — Android 10+ иначе часто блокирует старт из фона.
6. Отключите оптимизацию батареи для этого приложения.
7. Нажмите **Сохранить и работать в фоне**.

После этого иконку можно не открывать. Появится постоянное уведомление «Автозапуск магнитолы».

## Сборка

Нужны JDK 17 и Android SDK.

```bash
./gradlew assembleDebug
```

APK: `app/build/outputs/apk/debug/app-debug.apk`.

Минимальная версия Android: 5.0 (API 21). Целевая: API 34.
